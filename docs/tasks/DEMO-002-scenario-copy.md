# DEMO-002 — копирование сценария

## Scope

`POST /api/v1/scenarios/{scenarioId}/copy` (`copyScenario`) создаёт новый сценарий того же предприятия с теми же
машинами, базовыми поведениями, фазами и режимом цикла. Тело: `code`, `name`, необязательное `description`
(если не передано — берётся из исходного). Копия всегда `DISABLED` и проходит ту же проверку, что и создание:
409 при занятом коде, 422 при некорректных полях, 404 для неизвестного исходного сценария.

Копия нужна, чтобы запускать вариант сценария отдельно (другие машины, другая длительность фаз, живой показ),
не трогая исходный. Ограничения запуска не меняются: один realtime-прогон на машину, история не перезаписывается.

## Fix

`GET /api/v1/scenarios` без `search` отвечал 500: параметр `? IS NULL` не имел типа для PostgreSQL.
Параметр приведён к `text`; регрессия — листинг демо-сценариев без поиска.
